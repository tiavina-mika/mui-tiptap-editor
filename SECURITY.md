# Security Policy

## Supported Versions

Only the latest published major version of `mui-tiptap-editor` receives security fixes. Older
major versions are not backported.

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this package, please **do not open a public GitHub
issue**. Instead, report it privately using one of the following channels:

- [GitHub Security Advisories](https://github.com/tiavina-mika/mui-tiptap-editor/security/advisories/new)
  for this repository (preferred)
- Email [tiavinamika@gmail.com](mailto:tiavinamika@gmail.com)

Please include as much detail as possible: affected version, reproduction steps, and the
potential impact. You should receive an initial response within a few days. Once a fix is
available, a new version will be published via `semantic-release` and a GitHub advisory/release
will credit the report unless anonymity is requested.
